Данный проект представляет собой консольное приложение на языке Java, реализующее шифр 
Цезаря для работы с текстовыми файлами. Программа позволяет шифровать и расшифровывать текст
с использованием заданного ключа, а также демонстрирует принципы объектно-ориентированного 
программирования.


- Main

Класс Main является точкой входа в приложение.
В нём реализовано консольное меню, обеспечивающее взаимодействие пользователя с программой. Класс отвечает за:

выбор режима работы (шифрование или расшифровка);
ввод путей к файлам и ключа шифрования;
вызов соответствующих методов обработки файлов;
обработку возможных ошибок ввода и выполнения.


- BufferedFileProcessor

Класс BufferedFileProcessor реализует интерфейс FileProcessor и выполняет обработку файлов
построчно с использованием буферизированного ввода-вывода. Данный класс предназначен для работы
с большими текстовыми файлами, так как не загружает файл полностью в оперативную память.


- StringFileProcessor

Класс StringFileProcessor также реализует интерфейс FileProcessor, но выполняет обработку файла целиком, считывая его содержимое в строку.
Данный способ отличается простотой реализации и подходит для работы с небольшими файлами.


- Cipher

Класс Cipher реализует алгоритм шифра Цезаря.
В классе задаётся алфавит, используемый для шифрования, и реализованы методы:

encrypt — шифрование текста с использованием заданного ключа;

decrypt — расшифровка текста с использованием заданного ключа.

Символы, отсутствующие в алфавите, остаются без изменений.
 

- Интерфейс CipherAlgorithm

Интерфейс CipherAlgorithm определяет контракт для алгоритмов шифрования.
Класс Cipher реализует данный интерфейс, что позволяет при необходимости заменить алгоритм шифрования без изменения остальной логики программы.


- Интерфейс FileProcessor

Описывает операции работы с файлами. Определяет методы для шифрования и расшифровки
текстовых файлов с использованием заданного алгоритма шифрования.


- InputValidator
Перед обработкой данных выполняется валидация входных параметров.
Проверяется существование и доступность входного файла, а также корректность
ключа шифрования. Ключ нормализуется по длине алфавита, что предотвращает выход
за пределы допустимого диапазона.
